# 🕉️ Puranas Quiz

An interactive quiz platform based on the 18 Mahapuranas of Hindu mythology.

Users can explore Puranas, attempt quizzes, track scores, and view leaderboards.

## 🚀 Features

- User Registration & Login
- JWT Authentication
- Explore 18 Mahapuranas
- Quiz system
- Score tracking
- Leaderboard
- Admin panel
- MongoDB database integration

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- Python
- Flask
- Flask-CORS
- JWT Authentication

### Database
- MongoDB Atlas
